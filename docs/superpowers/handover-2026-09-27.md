## 6. Tool quirks learned (Windows, claude-in-chrome)

**YouTube Studio upload**
- The page is zoomed out, so coordinate and ref clicks can miss.
- To enter text:
  1. Take a screenshot first to wake the renderer.
  2. Click the title box around (620,213), press Ctrl+A and type.
  3. Click the description box and type **without** Ctrl+A. On an empty box, Ctrl+A types a stray "a".
- Set the radio buttons and click Next/Done with JS.
- Wait for "Checks complete" before Publish. Otherwise a "still checking" dialog appears: choose Go back and wait.

**File uploads:** `file_upload` is capped at 10 MB. For anything larger, the user attaches the file themselves.

**TikTok Studio**
- Never set the caption with execCommand; it crashes the editor. Type it with keystrokes instead.
- Time: click the options in `.tiktok-timepicker-option-text` with JS.
- Date: pick it in the calendar.

**Meta Business Suite reels composer**
- The user attaches the file.
- Type the caption, then click Next twice and choose Schedule.
- Type the date as `dd/mm/yyyy` in the textboxes, then fill the hours and minutes spinbuttons. Asia/Shanghai is +08:00.

**Hidden or minimized windows:** large JS evaluations and screenshots can time out. Retry with lighter calls, or ask the user to restore the window.

**Bash:** heredocs can lose backslashes. For complex edits, write the Python to a file with the Write tool and use forward-slash paths.
